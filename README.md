# Remix of Connect Chat

انشئ تطبيق باسم شات عالمي نفس هذا تمام مع من حيث المحتوئ والقوائم والصفحات والازارا والاشعارات واضف مميزات احترافي لجعل التطبيق جاهز ومتكامل، صفحة الدخول — دخول سريع، دخول بالعضوية، اشتراك



💬 غرفة الدردشة — رسائل، شريط أدوات علوي، حقل إدخال، بانر ترحيب



🚪 صفحة الغرف — قائمة بجميع الغرف مع عدد المتصلين



👤 الملف الشخصي — بيانات الحساب، تبويبات، رمز الهوية



📋 القائمة — أخبار الشات، قوانين UGC، الخصوصية



👥 المتصلين — شبكة المستخدمين المتصلين



🔊 إعدادات الصوت — تحكم كامل بالأصوات



📱 شريط تنقل سفلي — 8 أزرار للتنقل السريع،أضف تسجيل اسم المستخدم والعمر والنوع ذكر او انتى عند الدخول كزائر ،اضف ازار التنقل بين الصفحات وازرار الصفحات،صفحة الدردشة خاصه لكل غرفه،اضف الملف الشخصي لكل مستخدم ،عند الضغط على صوره المستخدم في الدردشه ظهور خيارات صفحه المستخدم و الرساله خاصه وعرض الملف الشخصي الخاص بالمستخدم ،اضف صفحه الرسائل الخاص،اضف نظام تسجيل دخول حقيقي،اضف عند عند انشاء حساب الاسم والعمر والنوع،اضيف فمن القوائم عند فتح التطبيق والبدء يكون هناك دردشة عامه للجميع مع صفحة كتابه الدردشه،اضافة ايقونة البحث في قائمة المتصلين او الأعضاء مع خيارات تحديد النوع ذكر او انثئ عضو او زائر،اضافة صورة شخصية للمستخدم واضافه امكانية تعديل الملف الشخصي مع اضافة الازار وطلب الصداقه إضافة تعديل الألوان للخط والاسم.
